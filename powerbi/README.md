# Power BI handoff

This repository includes a reproducible dashboard **specification** and measure definitions. It does **not** include or claim a completed `.pbix` file.

## Data to import

Use [`../excel/311_operational_summary.csv`](../excel/311_operational_summary.csv), the aggregate output generated by `src/build_project.py`.

The CSV has one row for each combination of:

- `dimension`: `complaint_type`, `agency`, or `borough`
- `label`: the category name
- `requests`
- `resolved_requests`
- `closure_rate_percent`
- `total_elapsed_resolution_hours`
- `median_resolution_hours`
- `p90_resolution_hours`

This is a portfolio-friendly aggregated handoff. It is suitable for category, agency, and borough comparisons, but it cannot reconstruct a row-level distribution or a global median from grouped medians.

## Build steps

1. In Power BI Desktop, choose **Get data → Text/CSV** and select `excel/311_operational_summary.csv`.
2. Name the table `311 Operational Summary`.
3. Set numeric columns to decimal or whole-number types as appropriate.
4. Add the measures in [`measures.dax`](measures.dax).
5. Follow the layout and metric-usage guardrails in [`dashboard-spec.md`](dashboard-spec.md).
6. Add a visible scope note: “Requests created 2025-01-02; raw snapshot not published; elapsed time is `closed_date − created_date` where both timestamps are valid.”

## Metric guardrails

- `median_resolution_hours` and `p90_resolution_hours` are already calculated **within each row's group**. Do not sum or average them to claim a global median or global P90.
- For a category card, show those values only when a single `dimension` and single `label` are selected.
- The published overall median (10.52 hours) and P90 (332.87 hours) come from the underlying request-level snapshot and are documented in [`../outputs/summary_metrics.json`](../outputs/summary_metrics.json).
- The 5,392.99 recorded-elapsed-hours scenario is illustrative, not a savings measure. It uses the sum of recorded elapsed time rather than `requests × median`. Keep its disclaimer visible in any report.
